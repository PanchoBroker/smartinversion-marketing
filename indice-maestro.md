**Implicación práctica para el usuario como administrador:** hasta que se decida construir una interfaz de gestión real, la única herramienta operativa hoy es el panel de Supabase Studio (o SQL directo) — incluida la propia asignación de rol nombrado que le queda pendiente a G0-R05 (Bloque B5).
